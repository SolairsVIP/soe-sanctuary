# PD2 中文维基地图图标

本目录的原始 28×28 PNG 来自 [PD2 中文维基地图资料](https://wiki.projectdiablo2.cn/wiki/Maps)，作为“暗金地图”类别的示例图标：

- [fallen-gardens.png](https://wiki.projectdiablo2.cn/w/images/9/9d/Map_Icon_Fallen_Gardens.png)：堕落花园（`t53`）。
- [imperial-palace.png](https://wiki.projectdiablo2.cn/w/images/b/b7/Map_Icon_Imperial_Palace.png)：帝国皇宫（`t54`）。
- [outer-void.png](https://wiki.projectdiablo2.cn/w/images/d/df/Map_Icon_Outer_Void.png)：虚空外（`t55`）。

它们都是 [PD2 的暗金地图](https://wiki.projectdiablo2.cn/wiki/Item_Filtering)，并且对应 SoE v13.0.2 物品表中的暗金地图代码。游戏素材权利归原权利人所有。
