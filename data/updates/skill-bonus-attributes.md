# 技能加成属性说明（S2）

装备上的“灵气效果”“诅咒效果”“技能范围”等属性，作用是**在技能原本的数值上再乘一次**。本文列出每种属性的计算方法，以及它影响哪些技能。

所有算例统一按 **20 级技能（20 点硬点，没有 +技能、没有协同）** 计算。游戏里每一步除法都会抹去小数，本文的算例也按这个规则。

<a id="overview"></a>
## 一页看懂

| 属性 | 加成怎么算 | 上限 | 影响的技能 |
|---|---|---|---|
| 灵气效果 | 灵气效果 × 60 ÷ (灵气效果 + 25) | +60% | 23 个：圣骑士灵气、脆弱、黑暗统帅光环 |
| 诅咒效果 | 诅咒效果 × 70 ÷ (诅咒效果 + 22) | +70% | 12 个：死灵法师诅咒等 |
| 技能范围 | 技能范围 × 70 ÷ (技能范围 + 18) | +70% | 81 个技能的半径 |
| 技能范围提高 | 数值直接加到半径上 | — | 同“技能范围” |
| 技能增益效果 | 属性值是多少就加多少 % | 无递减 | 27 个：战吼、附魔、护甲类等 |
| 技能持续时间 | 属性值是多少就加多少 % | 无递减 | 63 个增益或诅咒的持续时间 |
| 技能频率 | 间隔 × (100 − 属性值) ÷ 100 | — | 10 个技能的间隔 |

通用算法：

```
最终值 = 技能原数值 × (100 + 加成%) ÷ 100
（每一步除法都抹去小数）
```

举例：20 级力量给队友的伤害是 +210%，身上有 25 点灵气效果（查表是 +30%）：

```
210 × (100 + 30) ÷ 100 = 273
队友伤害变成 +273%
```

两种范围属性同时有时是先加后乘。例如 20 级力量有 18 点技能范围（+35%）和 2 点技能范围提高：

```
(77 + 2) × 135 ÷ 100 = 106
光环半径 51.3 码 → 70.6 码
```

## 1. 灵气效果

**只影响圣骑士的灵气、脆弱和黑暗统帅光环。** 其他职业的光环、战吼、德鲁伊灵气，以及佣兵和怪物的光环，都不吃灵气效果。

```
加成% = 灵气效果 × 60 ÷ (灵气效果 + 25)
```

| 灵气效果 | 加成 |
|---|---|
| 0 | 0 |
| 5 | +10% |
| 10 | +17% |
| 15 | +22% |
| 20 | +26% |
| 25 | +30% |
| 30 | +32% |
| 40 | +36% |
| 50 | +40% |
| 75 | +45% |
| 100 | +48% |

几件装备的灵气效果直接相加后再查表。例如 5 + 5 + 10 = 20 点，按 20 查表是 +26%。

## 3. 技能范围 / 技能范围提高

两个属性影响同一批技能，都是改技能的半径：

- **技能范围**按百分比放大：`加成% = 技能范围 × 70 ÷ (技能范围 + 18)`，上限 +70%。
- **技能范围提高**把数值直接加到半径上。

```
新半径 = (原半径 + 技能范围提高) × (100 + 加成%) ÷ 100
```

| 技能范围 | 加成 |
|---|---|
| 0 | 0 |
| 5 | +15% |
| 10 | +25% |
| 15 | +31% |
| 20 | +36% |
| 25 | +40% |
| 30 | +43% |
| 40 | +48% |
| 50 | +51% |
| 75 | +56% |
| 100 | +59% |

几件装备的技能范围直接相加后再查表。

**只影响下面这几个技能的触发或脉冲间隔。** 属性越高，间隔越短。

```
新间隔 = 原间隔 − 原间隔 × 技能频率 ÷ 100
```

### 受影响的技能

算例按 **20 点技能频率** 计算。25 帧等于 1 秒。

| 技能 | 来源 | 20 级间隔 → 加成后（算例） |
|---|---|---|
| 爆裂箭 | 亚马逊 | 爆炸间隔 2 − 2×20÷100 = 2 帧（0.08 秒 → 0.08 秒） |
| 雷云风暴 | 法师 | 脉冲间隔 25 − 25×20÷100 = 20 帧（1.00 秒 → 0.80 秒） |
| 圣火 | 圣骑士 | 脉冲间隔 25 − 25×20÷100 = 20 帧（1.00 秒 → 0.80 秒） |
| 神圣冰冻 | 圣骑士 | 脉冲间隔 25 − 25×20÷100 = 20 帧（1.00 秒 → 0.80 秒） |
| 神圣冲击 | 圣骑士 | 脉冲间隔 25 − 25×20÷100 = 20 帧（1.00 秒 → 0.80 秒） |
| 庇护所 | 圣骑士 | 脉冲间隔 25 − 25×20÷100 = 20 帧（1.00 秒 → 0.80 秒） |
| 火山爆 | 德鲁伊 | 喷发间隔 1 − 1×20÷100 = 1 帧（0.04 秒 → 0.04 秒） |
| 龙卷风 | 德鲁伊 | 间隔 15 − 15×20÷100 = 12 帧（0.60 秒 → 0.48 秒） |
| 刃之怒 | 刺客 | 间隔 4 − 4×20÷100 = 4 帧（0.16 秒 → 0.16 秒） |
| 刀刃之盾 | 刺客 | 间隔 20 − 20×20÷100 = 16 帧（0.80 秒 → 0.64 秒）；脉冲间隔 10 − 10×20÷100 = 8 帧（0.40 秒 → 0.32 秒） |

说明：

- 间隔是整数帧，基数小的技能要堆得比较高才会见效。例如刃之怒间隔 4 帧，25 点技能频率才降到 3 帧，50 点才降到 2 帧（2 帧是它的下限）。
- 时术师四阶的升华会直接赋予技能频率。


数值取自 S2 技能表（2026-11-25）。
