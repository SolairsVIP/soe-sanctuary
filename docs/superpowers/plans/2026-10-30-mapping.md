# 刷图系统资料页实施计划

**目标：** 为流放圣所制作可搜索的刷图资料页，帮助玩家查地图、通货效果和常用配方。

**架构：** 沿用现有静态网站和独立升华页的做法，使用独立的 HTML、CSS、JavaScript 与本地 JSON 快照。地图阶级取 Mod 物品表，中文资料与机制来自原资料站；无法核对的信息明确留空。

**约束：** 道具图片展示不超过原始 28×28 像素；T4 可以复用炼狱地图图标，但两类地图的规则和数据分开；不臆测 T3.5 的阶级规则；区分游戏模式；保持首页现有内容和用户修改。

## 工作内容

- [x] 记录来源与版本，整理地图、通货、使用限制和常用配方数据。
- [x] 增加独立资料页，提供概览、地图筛选、通货筛选与详情、配方说明和来源链接。
- [x] 将首页的刷图入口连接到新页面，保留原站链接作为资料来源。
- [x] 验证中文、英文、别名和代码搜索、阶级筛选、缺失资料、图标尺寸与页面适配。

## 重点检查

- 普通地图以实际物品类型判定 T1–T3，不以物品代码首位推断。
- T3.5 与 T4 的首领伤害和抗性没有对应数据时显示“暂无数据”。
- 原站的部分道具描述有冲突，优先呈现刷图规则页内可明确核对的数值。
- 地图通货的可用条件、上限及重铸后果应有出处；不把恐怖复制粘贴错误当作已验证规则。
- 恐怖、铭文、凿子和憎恶宝珠的名称、图标及物品代码正确对应。
